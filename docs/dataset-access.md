# 데이터셋 접근 기록 (백로그 3번)

README §14.1 백로그 3번("데이터셋 접근 신청/라이선스·누수 구조 확인")의 기록이다. 역할은 README §6.1을 따른다.
작성일: 2026-11-12. 법률 자문이 아니다. 확인하지 않은 내용은 "확인 필요"로 적었다.

**근거의 종류.** 아래에서 "확인된 것"은 세 가지 중 하나다.

- (신청) 저장소 소유자가 직접 한 신청 절차.
- (HF 메타데이터) Hugging Face 공개 API `https://huggingface.co/api/datasets/<id>`가 2026-11-12에 돌려준 값. 데이터셋 파일은 받지 않았다. 메타데이터의 라이선스 태그는 게시자가 붙인 값이며, 이것만으로 이용 조건 전체를 확인한 것은 아니다.
- (README) README §6.1·§6.5에 이미 적힌 프로젝트 규칙.

## 요약

| 데이터셋 | 역할 (README §6.1) | 접근 상태 | 신청 날짜 |
|---|---|---|---|
| DeepSpeak v2 | 주 학습 / 내부 검증 | 접근 요청함, 승인 대기 | 확인 필요 |
| Deepfake-Eval-2024 | 최종 외부 실전 평가 전용 | 접근 요청함, 승인 대기 | 확인 필요 |
| TalkingHeadBench | 우선 외부 생성 방식 일반화 평가 | 접근 방법 확인 필요 (신청·다운로드 안 함) | 해당 없음 |

세 데이터셋 모두 아직 파일을 받지 않았다. 이 저장소에는 어떤 데이터셋의 영상이나 파생물도 넣지 않는다 (README §6.5).

## DeepSpeak v2

- 위치: `faridlab/deepspeak_v2` (Hugging Face)
- **역할:** 진짜 + (a) 아바타·(b) 립싱크·(c) 얼굴 교체를 이용한 주 학습/내부 검증. README §13.1 기준으로 내부 학습·검증·홀드아웃.
- **접근 상태:** Hugging Face에서 안내하는 외부 양식을 작성한 뒤 접근을 요청했다. 승인 대기 중이다. 신청 날짜: **확인 필요.**

| 확인된 것 | 근거 |
|---|---|
| 접근 제한이 있고 수동 승인 방식이다 (`gated: manual`) | HF 메타데이터 |
| 라이선스 태그는 `other`, 이름은 `deepspeak-v2-0-license`이고, 조건 문서 링크가 따로 있다 | HF 메타데이터 |
| 접근 양식과 이용 조건을 따르고, 사용 시 출처를 표기한다 | README §6.5 |

| 확인 필요 | 비고 |
|---|---|
| `deepspeak-v2-0-license` 문서의 실제 조항 (허용 목적, 재배포, 파생물, 삭제 의무 등) | 링크만 확인했고 본문은 읽지 않았다 |
| 외부 양식에서 동의한 조건의 내용 | 제출한 사본이 있으면 여기에 요약한다 |
| 인물 ID와 원본 녹화 계보 정보가 제공되는지 (그룹 분할에 필요) | 접근 승인 후 확인 |
| 공식 분할의 구성과 누수 위험 | 접근 승인 후 확인 |
| 승인까지 걸리는 시간, 승인 결과 | 대기 중 |

## Deepfake-Eval-2024

- 위치: `nuriachandra/Deepfake-Eval-2024` (Hugging Face)
- **역할:** 최종 외부 실전 평가 전용. 학습·튜닝·임계값 결정에 쓰지 않는다 (CLAUDE.md, README §6.1). 반복적인 모델 수정 피드백에도 쓰지 않는다.
- **접근 상태:** Hugging Face에서 접근을 요청했다. 기관 이메일과 관련 작업 링크를 제출했다. 승인 대기 중이다. 신청 날짜: **확인 필요.**

| 확인된 것 | 근거 |
|---|---|
| 접근 제한이 있고 수동 승인 방식이다 (`gated: manual`) | HF 메타데이터 |
| 신청 양식 항목: 이름, 소속, 기관 이메일, 국가, 날짜, 사용 목적, 딥페이크 탐지 또는 관련 분야 작업을 보여 주는 검증 가능한 링크 | HF 메타데이터 |
| 양식 안내: 불완전하거나 질문에 직접 답하지 않은 응답은 거절되며, 제출 후 수정할 수 없다 | HF 메타데이터 |
| 이용 조건: **평가에만** 쓸 수 있다. 학습에 쓰는 것은 이용 조건 위반이다 | HF 메타데이터 (Terms of Use) |
| 이용 조건: 개인·기관·사회에 해를 줄 수 있는 기술의 개발·개선에 쓰지 않는다 | HF 메타데이터 (Terms of Use) |
| 라이선스 태그는 `cc-by-sa-4.0`이다. 상업적 이용의 적법성은 사용자가 직접 확인해야 한다 | HF 메타데이터 |

데이터셋의 "평가 전용" 조건은 TRINITY의 규칙(최종 평가 전용)과 같은 방향이다.

| 확인 필요 | 비고 |
|---|---|
| 승인 결과 | 대기 중 |
| 임계값 결정·확률 보정이 "평가"에 포함되는지에 대한 게시자 측 해석 | TRINITY는 어느 쪽이든 쓰지 않는다 |
| CC-BY-SA-4.0 아래에서 결과·파생물을 공개할 때의 표기와 동일조건 의무 범위 | 결과 보고 전 확인 |
| 수집된 원 영상(제3자 콘텐츠)의 권리 관계와 보관·삭제 조건 | 확인하지 않음 |
| 영상 중 "말하는 사람 한 명"이라는 TRINITY 분석 범위에 맞는 표본 수 | 접근 승인 후 확인 |
| README §6.5의 "구체적 신청 기한" | 메타데이터에서 기한 정보는 찾지 못했다 |

## TalkingHeadBench

- 위치: `luchaoqi/TalkingHeadBench` (Hugging Face)
- **역할:** 우선 외부 생성 방식 일반화 평가. 별도로 허용된 학습 분할은 추후 선택한다. 학습에 쓰면 그 부분은 더 이상 독립적인 외부 평가 자료가 아니라고 명시한다 (README §6.1).
- **접근 상태:** 접근 방법 **확인 필요.** 신청하지 않았고 파일을 받지 않았다.

| 확인된 것 | 근거 |
|---|---|
| HF 메타데이터상 접근 제한 표시가 없다 (`gated: false`) | HF 메타데이터 |
| 라이선스 태그는 `mit`이다 | HF 메타데이터 |

| 확인 필요 | 비고 |
|---|---|
| 실제 다운로드 절차와 별도 동의·양식이 있는지 | 메타데이터에 제한 표시가 없다는 것만 봤다. 데이터셋 카드 본문은 읽지 않았다 |
| `mit` 태그가 영상 데이터 전체에 적용되는지, 상위(원본) 영상의 권리는 어떤지 | README §6.1의 "상위 영상 권리" 항목 |
| 제공 분할의 구성 (학습/평가 구분, 생성 방식별 표본 수) | README §6.1 |
| 인물·원본 계보 정보 제공 여부, DeepSpeak와 인물·원본이 겹치는지 | 누수 검사에 필요 |

## 백로그 3번 완료 조건 대조

| 완료 조건 (README §14.1) | 상태 |
|---|---|
| 접근 상태·사용 조건 | 접근 상태는 기록함. 사용 조건은 위 "확인된 것"까지만. DeepSpeak 라이선스 본문 등은 확인 필요 |
| 최소 테스트 샘플 | 없음. 어떤 데이터셋도 받지 않았다 |
| 공통 manifest/분할 규칙 확보 | 없음. README §6.4에 계획 필드만 있다. 실제 데이터셋 필드를 본 뒤 정한다 |

백로그 3번은 **진행 중**이다. 5번(WaveRep 스파이크)은 데이터셋 대신 본인 촬영 영상 1개로 실행 가능성만 확인했고, 8번(데이터 위생·평가 파이프라인)은 3번이 끝나야 시작할 수 있다.

## 다음에 할 일

1. 두 데이터셋의 신청 날짜를 적는다 (저장소 소유자가 알려 주면 반영).
2. 승인 결과가 오면 날짜와 함께 기록하고, 승인 조건을 "확인된 것"으로 옮긴다.
3. DeepSpeak v2 라이선스 문서 본문을 읽고 조항을 정리한다.
4. TalkingHeadBench 데이터셋 카드와 논문에서 접근 절차, 분할, 권리 관계를 확인한다.
5. 접근이 열린 데이터셋부터 최소 테스트 샘플을 `data/research/` 아래(Git 제외)에 두고, 실제 필드를 README §6.4의 공통 레코드에 대응시킨다.
