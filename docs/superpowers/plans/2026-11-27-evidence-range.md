## 영상을 열기 전에 고정할 예약

docs/seamless-reservation.md의 filelist SHA-256과 기존 두 CSV 해시를 검증한다. 공식 train의 naturalistic train_candidate만 남긴다. 기존 내부 test 200·dev 100·pilot 10쌍의 양쪽 P 코드, 세션, 원본 계보 및 공식 dev/test와의 교집합이 비었는지 다시 검사한다. 기관 간 P 코드 중복, 접미사 ID, 모호한 쌍은 기존 제외 규칙을 유지한다.

시드 20261127, 역할 range_fit → range_check 순서로 기관별 최대 잔여법과 sha256(시드|역할|키) 정렬을 적용한다. 동률은 기관 번호 순이다. 두 참가자와 세션을 모두 점유하고 기존 A-select 방식으로 한 사람의 영상 한 편만 사용한다. 다른 역할·향후 학습에는 양쪽 참가자와 녹화 계보를 모두 격리한다. 기관 할당 미달과 Gate 탈락은 그대로 보고하며 결과를 보고 사람을 보충하지 않는다. 재현·교집합·기관별 개수 테스트 후 목록은 Git 밖에 두고 스크립트·입력·역할별 CSV의 SHA-256만 미디어 접근 전 커밋한다.

PR #40의 Seamless V0 Gate 통과는 2/8이었다. 25%는 작은 표본의 예산 가정이다. 160명을 100/60으로 예약하면 기대 통과는 25/15명이다. 500/300 슬롯이 모두 채워진다는 가정에서 기대 통과는 125/75명이다. 목표 100/60명의 기대 소요량은 각각 100÷0.25=400명, 60÷0.25=240명으로 총 640명이다. 이 수도 목표 달성을 보장하지 않는다. 기존 후보 1,115명 중 한 쌍의 두 참가자를 모두 점유하므로 독립 예약은 이론상 최대 557쌍이며 세션 제약으로 더 줄 수 있다.

**예약 상한은 800명(fit 500, check 300), 목표 통과는 100/60명으로 사전 고정한다.** 역할별 순번은 기존 order 해시 방식으로 봉인한다. 12-03의 1-B(Vab) 결정 뒤 확정된 하나의 Gate 버전에서만 측정한다. 각 역할을 순서대로 처리하고 원본 25초에서 Gate 적합 구간이 하나 이상인 서로 다른 A가 목표에 도달하면 그 역할을 종료한다. 재압축 통과나 축 성공 여부로 추가 모집하지 않는다. 예약이 소진되면 배정·처리·통과·신호별 성공 수와 부족분을 그대로 보고한다. 신호별 공개 최소치 50/30은 별도로 적용한다. 이후 Gate 변경 시 다른 기준 버전으로 분리한다.

**저장·전송 예산.** 여유 약 28GB에서 동시 원본은 A 한 사람분(MP4와 대응 WAV 각 1개)으로 제한한다. B, NPZ, 다음 사람의 파일을 미리 받지 않는다. 내려받은 즉시 25초 전처리본의 길이·오디오·해시를 확인하고 원본을 삭제한다. 두 조건 측정 후 파생 미디어와 임시 파일도 삭제하고 집계·버전·해시만 보존한다. 실패·중단 시 부분 파일을 정리한 뒤 재개한다.

## 백분위와 불확실성

조건·신호별로 range_fit 사람 한 명의 성공 구간 중 가장 큰 값 하나만 기준 분포에 넣는다. 성공 구간이 없으면 해당 분모에서 제외한다. 화면의 각 구간값 x는 그대로 두고, 기준 사람별 최댓값 중 x보다 작은 수와 동점 수의 절반을 더해 유효 인원 N으로 나눈 백분위 p를 표시한다. “진짜 영상 N편에서 각각 시차가 가장 컸던 순간과 비교하면, 이 구간은 큰 쪽 약 x%에 듭니다.” 상위 비율은 100−p다.

사람 단위 목표는 ‘어느 구간에서든 한 신호 이상 드묾’ 5%다. WaveRep와 SyncNet에 단측 2.5%씩 고정 배분한다(Bonferroni). 한 축이 실패하거나 축소돼도 남은 축의 몫은 늘리지 않는다. 유효 인원 N의 최댓값을 오름차순으로 정렬해 ceil(0.975×(N+1))번째를 경계로 쓴다. 해당 순위가 N보다 크면 비교 보류, 경계와 동점이면 드묾으로 표시하지 않는다. 기관별 사람 단위 복원추출 2,000회(시드 20261127)에서 두 신호와 압축 쌍을 함께 유지해 p의 95% 구간을 계산한다. 관찰값이 경계를 초과하고 p의 하한도 97.5 이상이어야 드묾이다. 불확실성 구간이 기준을 가로지르거나 두 압축 조건이 일치하지 않으면 보류한다.

독립 range_check에서 실제 화면 규칙을 그대로 재생한다. 한 구간·한 축이라도 드묾인 사람 수를 비교 가능한 사람 수로 나눈 값을 주 오탐률로 보고하고, 95% Wilson 구간과 전부 결측인 사람 수도 병기한다. 5% 초과 또는 신호별 fit 50명/check 30명 미달이면 해당 조합의 공개를 보류한다. 검증 결과로 경계를 조정하지 않는다. 25초 표본보다 긴 창은 더 많은 구간을 검색하므로 그 길이에서 사람 단위 검증 전까지 드묾 표시를 보류한다. 얼굴이 크고 잘 보이는 발화 영상 위주로 Gate를 통과하므로 기관별·얼굴 크기별 탈락률과 비교 가능 비율을 별도로 보고한다.

## 가짜 확인과 요약 라벨

기준 버전을 먼저 봉인한 뒤 사용 가능한 MAVOS-DD in-domain 가짜 또는 승인된 파일럿 MuseTalk 짝을 처리한다. 변조 계보·인물과 기준/검증 그룹 중복을 배제한다. 같은 전처리와 압축 조건에서 사람별 드묾 표시율, 판독 불가율, 원본 짝 대비 방향, 그룹 단위 95% 구간을 보고한다. 드문 실제 영상과 범위 안의 합성도 그대로 기록한다. 파일럿 수가 작거나 효과가 불분명하면 기술적 관찰로만 남긴다. open-set·외부 최종 평가 분할은 봉인한다. 합성 영상과 프레임은 공개하지 않는다.

드묾은 관찰 문구다. 가짜 확인이 끝나도 이 관찰 하나로 요약을 승격하지 않는다. 현재처럼 검증된 fusion 묶음이 없으면 판정 가능한 요청의 요약은 항상 “판단 보류”다. 승인된 묶음이 해당 축 조합·조건을 지원하고 실제 assessed 라벨을 냈을 때만 기존 고정 경계에 따라 “의심 신호 발견 / 의심 신호 낮음”을 표시한다. 범위 밖 요청과 측정 실패의 상태는 기존 계약을 따른다.

## 화면과 인수 기준

§15.3 제안의 evidence_ranges를 PR #46의 세 구역에 연결한다. 첫 구역에서 원본 시간 구간을 고르면 둘째 구역에 해당 신호의 뜻과 측정 상태가 나오고, 셋째 구역에 기준 인원·조건·백분위와 불확실성, 보류 이유가 나온다. “참고 정보, 진위 단정 아님”을 유지한다. 기준이 없거나 이전 결과이면 기존 준비 중 문구를 사용한다. 완료 검사는 원본 시작점이 0이 아닌 클립, 동점, null, 추적 실패, 한 사람의 구간 복제, 압축 조건 불일치, 이전 앱과 녹화의 호환까지 포함한다.
