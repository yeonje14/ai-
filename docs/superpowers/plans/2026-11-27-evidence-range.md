## 백분위와 불확실성

그룹 단위는 세션이다. 조건·신호별로 range_fit 세션 하나에서 두 사람의 모든 성공 구간 중 가장 큰 값 하나만 기준 분포에 넣는다. 성공 구간이 두 사람 모두 없으면 해당 분모에서 제외한다. 화면의 각 구간값 x는 그대로 두고, 세션별 최댓값 중 x보다 작은 수와 동점 수의 절반을 더해 유효 세션 수 N으로 나눈 백분위 p를 표시한다. “진짜 대화 영상 N세션에서 각각 가장 컸던 순간과 비교하면, 이 구간은 큰 쪽 약 x%에 듭니다.” 상위 비율은 100−p다. 세션 최댓값은 한 사람 최댓값보다 크거나 같으므로 한 사람 영상의 오탐률은 세션 단위 오탐률 이하다.

세션 단위 목표는 ‘어느 사람·어느 구간에서든 한 신호 이상 드묾’ 5%다. WaveRep와 SyncNet에 단측 2.5%씩 고정 배분한다(Bonferroni). 한 축이 실패하거나 축소돼도 남은 축의 몫은 늘리지 않는다. 유효 세션 N의 최댓값을 오름차순으로 정렬해 ceil(0.975×(N+1))번째를 경계로 쓴다. 해당 순위가 N보다 크면 비교 보류, 경계와 동점이면 드묾으로 표시하지 않는다. 기관별 세션 단위 복원추출 2,000회(시드 20261127)에서 세션 안의 두 사람·두 신호·압축 쌍을 함께 유지해 p의 95% 구간을 계산한다. 관찰값이 경계를 초과하고 p의 하한도 97.5 이상이어야 드묾이다. 불확실성 구간이 기준을 가로지르거나 두 압축 조건이 일치하지 않으면 보류한다.

독립 range_check에서 실제 화면 규칙을 그대로 재생한다. 한 사람·한 구간·한 축이라도 드묾인 세션 수를 비교 가능한 세션 수로 나눈 값을 주 오탐률로 보고하고, 95% Wilson 구간과 전부 결측인 세션 수도 병기한다. 5% 초과 또는 신호별 fit 50세션/check 30세션 미달이면 해당 조합의 공개를 보류한다. 검증 결과로 경계를 조정하지 않는다. 25초 표본보다 긴 창은 더 많은 구간을 검색하므로 그 길이에서 세션 단위 검증 전까지 드묾 표시를 보류한다. 얼굴이 크고 잘 보이는 발화 영상 위주로 Gate를 통과하므로 기관별·얼굴 크기별 탈락률과 비교 가능 비율을 별도로 보고한다.

## 실행 (사용자가 터미널에서)

scripts/evidence_range_run.py. 세션마다 data/research/seamless/range_v2/<역할>/<order>/state.json에 기록하고 같은 명령으로 이어서 한다. 진행 로그(range_v2/run.log)는 한 줄에 처리 수·통과 수·남은 디스크·경과 시간만 쓴다.

- fetch: 역할 순서대로 한 세션씩 공식 S3 방법(research/seamless/fetch_pilot.py --role, data/research/seamless/.venv)으로 받고, 두 사람의 25초본을 만들어 확인한 즉시 원본을 지운다. 영구 실패(HTTP 거절·파일 누락·전처리 실패)는 원인을 기록하고 넘어간다. 네트워크·DNS 실패와 기록 없음은 다음 실행에서 다시 시도하고(세션당 3회), 연속 3세션이면 멈춘다.
- analyze(12-03 뒤): `--gate-version`이 코드의 GATE_VERSION과 같아야 하고, 첫 실행에서 기준 버전(range_v2/reference_version.json)을 봉인한다. 사람마다 두 조건 Gate, 원본 통과자만 해당 조건 통과 시 세 축. 정지 규칙을 적용한다. 구간별 WaveRep 값을 위해 프레임 번호와 logit을 결과에 남긴다(구간 경계 대응은 확인 필요).

## 가짜 확인과 요약 라벨

기준 버전을 먼저 봉인한 뒤 사용 가능한 MAVOS-DD in-domain 가짜 또는 승인된 파일럿 MuseTalk 짝을 처리한다. 변조 계보·인물과 기준/검증 그룹 중복을 배제한다. 같은 전처리와 압축 조건에서 사람별 드묾 표시율, 판독 불가율, 원본 짝 대비 방향, 그룹 단위 95% 구간을 보고한다. 드문 실제 영상과 범위 안의 합성도 그대로 기록한다. 파일럿 수가 작거나 효과가 불분명하면 기술적 관찰로만 남긴다. open-set·외부 최종 평가 분할은 봉인한다. 합성 영상과 프레임은 공개하지 않는다.

드묾은 관찰 문구다. 가짜 확인이 끝나도 이 관찰 하나로 요약을 승격하지 않는다. 현재처럼 검증된 fusion 묶음이 없으면 판정 가능한 요청의 요약은 항상 “판단 보류”다. 승인된 묶음이 해당 축 조합·조건을 지원하고 실제 assessed 라벨을 냈을 때만 기존 고정 경계에 따라 “의심 신호 발견 / 의심 신호 낮음”을 표시한다. 범위 밖 요청과 측정 실패의 상태는 기존 계약을 따른다.

## 화면과 인수 기준

§15.3 제안의 evidence_ranges를 PR #46의 세 구역에 연결한다. 첫 구역에서 원본 시간 구간을 고르면 둘째 구역에 해당 신호의 뜻과 측정 상태가 나오고, 셋째 구역에 기준 인원·조건·백분위와 불확실성, 보류 이유가 나온다. “참고 정보, 진위 단정 아님”을 유지한다. 기준이 없거나 이전 결과이면 기존 준비 중 문구를 사용한다. 완료 검사는 원본 시작점이 0이 아닌 클립, 동점, null, 추적 실패, 한 사람의 구간 복제, 압축 조건 불일치, 이전 앱과 녹화의 호환까지 포함한다.
