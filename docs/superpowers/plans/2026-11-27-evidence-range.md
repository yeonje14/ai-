# 4단계 계획 · 구간별 신호를 진짜 영상과 비교하기

승인 대기. 이번 PR은 계획과 계약 제안만 담는다. 분석 단위는 원본 시간으로 표시한 Gate 적합 구간이다. “전체 영상이 진짜일 확률”을 추정하지 않는다.

## 영상을 열기 전에 고정할 예약

docs/seamless-reservation.md의 filelist SHA-256과 기존 두 CSV 해시를 검증한다. 공식 train의 naturalistic train_candidate만 남긴다. 기존 내부 test 200·dev 100·pilot 10쌍의 양쪽 P 코드, 세션, 원본 계보 및 공식 dev/test와의 교집합이 비었는지 다시 검사한다. 기관 간 P 코드 중복, 접미사 ID, 모호한 쌍은 기존 제외 규칙을 유지한다.

시드 20261127, 역할 range_fit → range_check 순서로 기관별 최대 잔여법과 sha256(시드|역할|키) 정렬을 적용한다. 동률은 기관 번호 순이다. 두 참가자와 세션을 모두 점유하고 기존 A-select 방식으로 한 사람의 영상 한 편만 사용한다. 다른 역할·향후 학습에는 양쪽 참가자와 녹화 계보를 모두 격리한다. 기관 할당 미달과 Gate 탈락은 그대로 보고하며 결과를 보고 사람을 보충하지 않는다. 재현·교집합·기관별 개수 테스트 후 목록은 Git 밖에 두고 스크립트·입력·역할별 CSV의 SHA-256만 미디어 접근 전 커밋한다.

## 백분위와 불확실성

비교 조건·신호마다 기준 사람 한 명의 모든 성공 구간에 합계 가중치 1을 균등 배분한다. 비교값보다 작은 가중치와 동점 가중치 절반의 합을 전체 가중치로 나눈 값이 백분위 p다. 상위 비율은 100−p(%)다. 화면 예시는 “진짜 영상 N편과 비교했을 때 이 구간의 입과 소리 시차는 큰 쪽 약 x%에 들었습니다.” N은 해당 신호를 실제로 측정한 서로 다른 사람의 영상 수다.

측정 전 다음 규칙을 동결한다. 신호별 상위 단측 95백분위를 경계로 둔다. 기관 안에서 사람을 복원추출하고 그 사람의 모든 구간·압축 쌍을 함께 유지해 2,000회 반복한다(시드 20261127). p의 2.5·97.5백분위를 불확실성 구간으로 표시한다. 하한이 95 이상일 때만 “진짜 영상에서 드문 수준”, 구간이 경계를 가로지르면 “비교 보류”다. 신호별 유효 기준 50명 또는 검증 30명 미만이면 비교를 공개하지 않는다.

독립 range_check에는 기준 작성과 같은 처리를 적용한다. (a) 사람별 구간 오탐 비율의 평균, (b) 한 구간·한 신호라도 드묾으로 표시된 사람 비율을 함께 보고한다. (b)는 여러 구간을 살펴볼 때 증가할 수 있다. 각각 분자·분모·95% 구간과 결측 인원을 표시한다. 사람 단위 (b)가 목표 5%를 넘으면 해당 조합은 화면 출시 보류다. 검증 결과로 경계를 다시 고르지 않는다. 소표본에서 0건도 오탐이 없다는 보장은 아니다. 얼굴이 크고 잘 보이는 발화 영상 위주로 Gate를 통과하므로 기관별·얼굴 크기별 탈락률과 비교 가능 비율을 별도로 보고한다.

## 가짜 확인과 요약 라벨

기준 버전을 먼저 봉인한 뒤 사용 가능한 MAVOS-DD in-domain 가짜 또는 승인된 파일럿 MuseTalk 짝을 처리한다. 변조 계보·인물과 기준/검증 그룹 중복을 배제한다. 같은 전처리와 압축 조건에서 사람별 드묾 표시율, 판독 불가율, 원본 짝 대비 방향, 그룹 단위 95% 구간을 보고한다. 드문 실제 영상과 범위 안의 합성도 그대로 기록한다. 파일럿 수가 작거나 효과가 불분명하면 기술적 관찰로만 남긴다. open-set·외부 최종 평가 분할은 봉인한다. 합성 영상과 프레임은 공개하지 않는다.

드묾은 관찰 문구다. 가짜 확인이 끝나도 이 관찰 하나로 요약을 승격하지 않는다. 현재처럼 검증된 fusion 묶음이 없으면 판정 가능한 요청의 요약은 항상 “판단 보류”다. 승인된 묶음이 해당 축 조합·조건을 지원하고 실제 assessed 라벨을 냈을 때만 기존 고정 경계에 따라 “의심 신호 발견 / 의심 신호 낮음”을 표시한다. 범위 밖 요청과 측정 실패의 상태는 기존 계약을 따른다.

## 화면과 인수 기준

§15.3 제안의 evidence_ranges를 PR #46의 세 구역에 연결한다. 첫 구역에서 원본 시간 구간을 고르면 둘째 구역에 해당 신호의 뜻과 측정 상태가 나오고, 셋째 구역에 기준 인원·조건·백분위와 불확실성, 보류 이유가 나온다. “참고 정보, 진위 단정 아님”을 유지한다. 기준이 없거나 이전 결과이면 기존 준비 중 문구를 사용한다. 완료 검사는 원본 시작점이 0이 아닌 클립, 동점, null, 추적 실패, 한 사람의 구간 복제, 압축 조건 불일치, 이전 앱과 녹화의 호환까지 포함한다.
